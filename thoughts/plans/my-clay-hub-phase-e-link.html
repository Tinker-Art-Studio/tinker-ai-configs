The link contract (E-1 writes it down once; both sides test against it)

PartExact rule
Envelope{v:1, kind, readTime, …}; kind ∈ member | staff | reconcile. Any other key, version or kind → 400.
readTime{seconds: "<decimal string>", nanos: <int 0..999999999>} from the source read's Timestamp, full nanosecond precision; stored as a Firestore Timestamp (sourceReadTime); compared as (seconds, nanos). Out-of-range or non-canonical → 400.
The gateLater than the stored sourceReadTime (or none stored) → apply, and always advance sourceReadTime and updatedAt, even when nothing else changes (result unchanged) — otherwise an A→B→A delivered out of order would end on B. Equal or earlier → stale, nothing written.
member{memberId, snapshot} or {memberId, tombstone:true}. memberId must match Membership Manager's own pattern (m_ + a version-4 UUID).
snapshot — rebuilt from allowed keys, never copied and trimmed name, email: a string, trimmed, else null · emailLower: email lowercased, or null · memberSince: a valid YYYY-MM-DD, else null · phoneLast4: Membership Manager's own phone rule (formatPhone: 10 digits, or 11 starting with 1) → its last 4, else null · retired: true only if the source is exactly true · stage: one of the six known stages, else "!malformed" · scheduledPause: null, or {startDate, endDate, processed}, or "!malformed" if not an object · pauseHistory: [], or a list whose entries are {startDate, endDate, priorTerm?} (legacy start/end mapped, the modern value winning) or "!malformed", or "!malformed" if not a list · scheduledCancellation: null, or {finalAccessDate}, or "!malformed" if not an object · every date: a valid YYYY-MM-DD as-is, missing → absent, anything else → "!malformed" (never raw text) · priorTerm: present only as true · processed: true only when the source scheduledAt is a valid timestamp (Q6).
StatusOnly deriveStatus. Its precedence stays: a removed/retired record is removed and onboarding/touring is not_yet before any malformed pause data is looked at — so the fixtures are stage-qualified.
members/{memberId} (stored)The snapshot fields + memberId, firstName (first word of name), lastInitial (first letter of the last word, or null), status, sourceReadTime, updatedAt, tombstone:false.
memberProfiles/{memberId} (stored; Phase F lets the member read it){memberId, firstName, name, email, status, memberSince, pause, finalAccessDate, updatedAt}. pause = the valid, processed window containing today (Denver), else the earliest valid processed window starting after today, else null, as {startDate, endDate}; finalAccessDate only if valid. No malformed marker and no phone digits ever reach it. Date-dependent, so the recompute rewrites it too.
staff{uid, staff: {name, role}} — sent only for granted users — or {uid, tombstone:true}. Granted = role exactly admin|manager|staff, active absent or true, appAccess absent or a list of strings, and (role manager/admin, or appAccess contains my-clay-hub). A deleted, ungranted or malformed users doc → a tombstone envelope; malformed also logs an error naming the uid only (it repeats each reconcile until fixed — accepted). Never email, PIN or appAccess.
staffRoster/staff_{uid} (stored){uid, name, role, sourceReadTime, updatedAt, tombstone:false}. The receiver ignores a tombstone for a uid it doesn't hold, so no roster doc is ever created for someone never granted.
reconcile{scope:'members', items:[member entries], held:[memberId]} or {scope:'staff', items:[granted staff entries]} — the complete set at one readTime. Sender: every live source doc needs a valid memberId; a memberId with more than one live doc goes into held (ids only); a live doc with a missing or malformed memberId aborts the whole member reconcile (nothing sent, error logged). Receiver: duplicate ids across items/held → 400; held ids are neither updated nor removed and are left out of every denominator; a held record whose sourceReadTime is at or after the batch's readTime is never removed (a newer trigger already landed).
Tombstones (stored)Replace the document entirely. members: {memberId, tombstone:true, status:'removed', sourceReadTime, updatedAt}. memberProfiles: {memberId, tombstone:true, status:'removed', updatedAt}. staffRoster: {uid, tombstone:true, sourceReadTime, updatedAt}. A later live record restores only the allowlist. (Vault copies taken earlier keep the old fields until the 56-day retention ages them out — noted in DATA-RESTORE.)
Responses200 {result: applied|unchanged|stale}; 400 malformed envelope; 409 a reconcile stopped by a threshold. Terminal for the sender: only 200, 400 and 409 (400 also logs an error: the two repos disagree). Everything else — 401/403/404, 429, 5xx, timeouts — throws, so the trigger is retried.
LoggingNever request bodies, names, emails, phone digits, notes or source documents — only memberId/uid, kind, result and counts.
